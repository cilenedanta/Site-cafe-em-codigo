A coleta roda no GitHub Actions. Para disparar pelo botão, cole um token do GitHub uma única vez. Ele fica salvo só neste navegador e nunca vai para o código do site.

  1. Abra GitHub → criar token (fine-grained).
  2. Em Repository access, escolha Only select repositories → Site-cafe-em-codigo.
  3. Em Permissions → Repository permissions, deixe Actions: Read and write.
